## 2. 配信指標の提案

### 推奨案A(許諾不要で今すぐ配信できる構成)

1. 米10年国債利回り — FRED `DGS10`
2. 米2年国債利回り — FRED `DGS2`
3. 米10年-2年スプレッド — `DGS10 − DGS2` を自前で計算
4. VIX(恐怖指数) — FRED `VIXCLS`
5. ドル円 — ECB 参照レート(Frankfurter)
6. 日本10年国債利回り — 財務省 CSV

株価指数は数値を載せず、「詳しく見る」ボタンからマーケットルーティンのサイトに誘導する。

### 案B(株価指数を載せる場合)

S&P Dow Jones Indices(S&P500・ダウ)、Nasdaq、日経から配信許諾を取得したうえで、FRED の `SP500` / `DJIA` / `NASDAQCOM` / `NIKKEI225` を有効化する。
実装では指標を「レジストリ + 有効化フラグ」で管理し、許諾が取れた指標をあとから1行でオンにできるようにする。

## 3. データ鮮度の注意点

- 07:00 JST = 前日 22:00 UTC(米国東部時間 18:00)。米国の債券・VIX の FRED 反映は翌営業日になるため、配信される値は **1〜2営業日前の終値** になる。そのため各行に「基準日」を表示する。
- 月曜朝の配信は金曜の値になる。

## 4. Flex Message カード設計

```
┌──────────────────────────────────┐
│ QUONTERRA ACADEMY                │ ← ヘッダー(濃紺 #0B1F3A、白文字)
│ 9月14日(月)                       │
│ 本日のマーケットルーティン          │
├──────────────────────────────────┤
│ 米10年債利回り   4.95%   ▲+12bp   │ ← プラス: 緑 #16A34A
│  9/10時点                         │
│ 米2年債利回り    4.56%   ▲+13bp   │
│ 10年-2年スプレッド 0.39%  ▼−1bp    │ ← マイナス: 赤 #DC2626
│ VIX             17.84   ▲+1.38    │
│ ドル円          154.04   ▼−0.14    │
│ 日本10年国債     2.920%  ▲+2.5bp  │
├──────────────────────────────────┤
│ [        詳しく見る        ]        │ ← uri アクション(URLは後で確認)
│ 出典: FRED, ECB, 財務省            │
│ ※投資助言ではありません             │
└──────────────────────────────────┘
```

- `altText`: `9/14(月) マーケットルーティン|米10年 4.95% ドル円 154.04 …`(通知・トーク一覧に表示される)
- 前日比: 利回り系は bp、それ以外は値の差分と % を表示。変化なしはグレー `#6B7280` で「±0」と表示
- 取得に失敗した指標は行ごと「取得できませんでした」(グレー)にして、ほかの指標は配信する
- 全指標の取得に失敗した場合は、配信を中止するか、テキストのフォールバック(「本日のデータ取得に失敗しました。サイトをご確認ください」+ リンク)を送る(Phase 1 で選択)

## 5. 実行・運用上の注意

- **Cron**: `0 22 * * 0-4`(UTC)= 月〜金 07:00 JST。
- **Vercel Hobby プラン**では実行タイミングが「指定時刻の1時間枠内(±59分)」になり、7:00〜7:59 のどこかで配信される。7:00 ちょうどに届ける必要があれば Pro プランが必要。
- **LINE の配信数**: broadcast は「友だち数 × 1通」が月間メッセージ数に加算される。無料のコミュニケーションプラン(月200通)では、友だちが10人程度いれば数日で上限に達する。料金プランの確認が必要。
- **二重配信の防止**: Cron の再実行に備え、`X-Line-Retry-Key`(日付から決まる UUID)を付けて同じ日の重複配信を防ぐ。
- **認証**: `CRON_SECRET` が未設定・空の場合は常に 500/401 を返す(`Bearer undefined` の一致を許さない)。比較は timing-safe で行う。
- **秘密情報**: `FRED_API_KEY` / `LINE_CHANNEL_ACCESS_TOKEN_ACADEMY` / `CRON_SECRET` は環境変数からのみ読み込み、ログには値を出さない。`.env*` は `.gitignore` 済み。
